Origem dos preços. O catálogo é um snapshot versionado no repositório, não uma consulta ao vivo. A Retail Prices API da Azure é pública e não autenticada, mas a AWS exige assinatura SigV4 e o Google Cloud exige chave de API — que não pode ficar em código de front-end. A integração ao vivo com as três nuvens depende de servidor e está prevista para a etapa de back-end.
